# Minesweeper Bot

A Python Minesweeper bot featuring screen recognition,
automatic gameplay, exact probability calculations,
Monte Carlo simulations, and experimental machine learning.

## Features

- Constraint-based Minesweeper solver
- Exact mine probability calculation
- Automated screen recognition and gameplay
- Minesweeper simulator
- Strategy benchmarking
- Monte Carlo rollouts
- Machine learning experiments

## Setup

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies.
4. Run the simulator to verify the installation.

## Main files

- minesweeper_bot.py — Solver and probability engine
- simulator.py — Minesweeper simulation
- screenrecognition.py — Screen recognition
- rollout_strategy.py — Monte Carlo strategy
